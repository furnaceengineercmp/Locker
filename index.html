Sesudah mengunduh
  • Simpan file index.html asli di komputer Anda. Setiap kali mengubah aplikasi, ubah file aslinya lalu kunci ulang dengan alat ini.
  • Upload hanya file hasil kunci ke GitHub, dengan nama index.html. Jangan upload file asli.
  • Versi lama yang pernah diupload tanpa kunci masih tersimpan di riwayat commit. Hapus repository lama dan buat yang baru, atau jadikan private.
  • Password diminta sekali per tab. Menutup tab berarti password diminta lagi.
